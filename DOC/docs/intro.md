# 简介

这是一个基于 [Docusaurus 3](https://docusaurus.io) 搭好的中文文档站骨架：官网首页、文档、博客、本地中文搜索、图片放大、GitHub Pages 部署配置都已经就位，你只需要把内容换成自己的。

## 目录结构

```text
DOC/
├── docs/                  # 文档内容（Markdown/MDX）
│   ├── intro.md
│   ├── install.md
│   ├── faq.md
│   ├── quick-start/       # 快速开始（自动生成侧边栏分组）
│   └── guide/             # 使用指南
├── blog/                  # 博客文章
├── src/
│   ├── css/custom.css     # 主题色、字体等全局样式
│   ├── pages/index.js     # 首页
│   └── components/        # 首页特性卡片等组件
├── static/img/            # 图片、logo 等静态资源
├── docusaurus.config.js   # 站点主配置（标题、导航、插件）
├── sidebars.js            # 侧边栏配置
└── package.json
```

## 这个骨架自带什么

| 能力 | 说明 |
| --- | --- |
| 文档 + 博客 | `preset-classic` 提供文档、博客、独立页面三套路由 |
| 侧边栏自动生成 | `sidebars.js` 用 `autogenerated`，按目录层级自动出菜单 |
| 中文全文搜索 | `@easyops-cn/docusaurus-search-local`，纯前端索引，不依赖 Algolia |
| 图片点击放大 | `docusaurus-plugin-image-zoom` |
| 暗色模式 | 跟随系统，右上角可手动切换 |
| 部署 | GitHub Pages 工作流已放在 `.github/workflows/deploy.yml` |
